Navy typographic composition with ivory serif headline and an independent book SVG illustration. The engine now supports the serif font and replaceable decoration; optional artwork may be omitted on constrained surfaces. Letter spacing is not supported.

## Reference and implementation differences

The application does not load these PNGs. It uses structured content, separate assets, typed composition families and explicit background/panel layering. Line breaks are measured for each surface and CTA wording differs from the references. Actual layouts reflow across the four required surfaces; these reference PNGs themselves are square-only concepts.
